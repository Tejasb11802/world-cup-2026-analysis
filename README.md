# 2026 FIFA World Cup Intelligence Report

Social media, broadcast, and sponsor performance analysis for the 2026 FIFA World Cup.

## Overview

This project analyzes the 2026 World Cup using publicly available data to demonstrate:
- Social media KPI quantification (views, impressions, engagements)
- Broadcast viewership analysis
- Sponsor exposure and brand value estimation
- Trend identification and benchmarking

## Data Sources

- **Social Media:** YouTube Data API, X/Twitter API
- **Broadcast:** Official FIFA and broadcaster viewership data
- **Sponsors:** Official FIFA partners list and brand mention tracking
- **Players:** Official World Cup stats and social media data

## Project Structure

world-cup-2026-analysis/

1. **Interactive Dashboard** - Streamlit app with KPI analysis
2. **PDF Report** - Professional analysis matching Zoomph's format
3. **Data & Code** - All code and processed data on GitHub
